# References and upstream resources

The original project directory contained local copies of research papers. They are cited here rather than redistributed because their publication licenses were not bundled with the files.

## Research context

- Gustavo Polleti. **Building a Language-Learning Game for Brazilian Indigenous Languages: A Case of Study** (2024).
- Gustavo Padilha Polleti, Fabio G. Cozman and Fabricio Gerardi. **A Simple Audio and Text Collection-Annotation Tool Targeted to Brazilian Indigenous Language Native Speakers**. RESOURCEFUL 2025, pp. 80-85.
- **Unified Knowledge-Graph for Brazilian Indigenous Languages: An Educational Applications Perspective**.

## Language resources

- [BiLGraph](https://github.com/gpadpoll/bilgraph) - lexical and knowledge-graph resources used by the original project.
- [UD Bororo-BDT](https://github.com/UniversalDependencies/UD_Bororo-BDT) - Bororo dependency treebank.

## Models and documentation

- [Meta MMS-TTS Bororo model](https://huggingface.co/facebook/mms-tts-bor).
- [Transformers MMS documentation](https://huggingface.co/docs/transformers/model_doc/mms).
- [OpenAI audio transcription documentation](https://platform.openai.com/docs/guides/speech-to-text).

Use each upstream resource according to its own license, access conditions and community-governance requirements.
